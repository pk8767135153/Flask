 
## Flask
Flask is a micro web framework written in Python. It is designed to be lightweight and easy to use, making it a popular choice for building web applications and APIs. <br>

Here are some of its key characteristics:<br>
Minimalistic: Flask provides the core tools needed to build a web application, but it's up to you to pick and choose which additional features to add. This makes it highly customizable.<br>
Modular: Flask is built on modular components, allowing you to add or remove parts as needed. This promotes flexibility and scalability.<br>
Easy to Get Started: Flask has a simple and intuitive syntax, making it easy for beginners to get started with web development.<br>
Extensible: You can extend Flask's functionality with various extensions that add features like database integration, form validation, authentication, and more.<br>
Built-in Development Server: Flask comes with a built-in development server that provides debugging tools and an interactive debugger.<br>
